# fb-clone-website

A simple **Facebook Clone Website** built as part of my Git & GitHub learning journey. This project helped me understand the fundamentals of working with Git, managing project files, creating commits, working with branches, and pushing code to GitHub.

## 📌 About the Project

This project is a front-end clone inspired by the basic layout and design of Facebook. The goal was not to build a fully functional social media platform, but to recreate the look and structure of a social media website while practicing web development and Git version control.

Through this project, I worked on creating a user interface that resembles a social media platform, including common elements such as navigation, user information, posts, and other Facebook-inspired components.

## 🎯 Purpose

The main purpose of this project was to practice:

* Git and GitHub fundamentals
* Creating and managing repositories
* Tracking changes with Git
* Making commits
* Working with branches
* Connecting a local project to GitHub
* Pushing code to a remote repository
* Understanding the basic workflow of version control

## 🛠️ Technologies Used

* **HTML** — Structure of the website
* **CSS** — Styling and layout
* **Git** — Version control
* **GitHub** — Repository hosting and project management

## ✨ Features

* Facebook-inspired user interface
* Social media-style layout
* User/profile section
* Post/feed section
* Navigation elements
* Responsive and structured front-end design
* Organized project files for version control
